# docs/ — Project Documentation

This directory contains project documentation, diagrams, and screenshots.

## Directory Structure

```
docs/
├── README.md              # This file
├── screenshots/           # Application screenshots
├── architecture/          # Architecture diagrams (Mermaid source)
├── deployment/            # Deployment guides
├── database/              # Database schema and migrations
└── modules/               # Per-module documentation
```

## Generating Diagrams

Architecture diagrams use [Mermaid](https://mermaid.js.org/). You can view them in any Mermaid-compatible viewer or VS Code with the Mermaid extension.

## Screenshots

Screenshots should be taken at 1920×1080 resolution (or 1440×900 for laptop). Name files descriptively:

- `dashboard-overview.png`
- `employee-management.png`
- `master-data.png`
- `candidate-registration.png`
